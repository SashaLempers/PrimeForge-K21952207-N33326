Third-party programs are not included. Their names, versions, factual console
output, and cryptographic hashes are recorded solely to identify the tools that
were used. Their own licenses govern those programs:

- Proth20 0.9.1: MIT-licensed upstream software; binary not redistributed here.
- PARI/GP 2.17.4: GPL-licensed upstream software; binary not redistributed here.
- CPython 3.12.13: only the version and output are recorded.

  attempt is documented but supplies no primality verdict.

Captured third-party web pages and API responses are not included because a
single redistribution grant could not be established for all 79 sources. The
public source manifests preserve URLs, queries, timestamps, byte counts, and
SHA-256 hashes so the scope and integrity of the dated audit remain inspectable.
